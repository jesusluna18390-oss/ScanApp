# EscanApp Android / GitHub

## Cómo subir a GitHub Pages

1. Crear un repositorio en GitHub.
2. Subir todos estos archivos.
3. Ir a:
   Settings → Pages
4. En "Branch" elegir:
   main / root
5. Guardar.

GitHub te dará un link como:
https://TUUSUARIO.github.io/TUREPO/

## Instalar en Android

1. Abrir el link desde Chrome.
2. Tocar los 3 puntos.
3. Elegir "Instalar aplicación".

La app quedará instalada como APK/PWA.
